## Platform

web

## Users

Primary users are creators, designers, consultants, founders, and small teams building repeatable AI-assisted design systems. Advanced users configure reusable agents, skills, knowledge, systems, and experimental run setups without giving up manual control.

## Product Purpose

Apollo Studio is a local-first creative operating system for designing, testing, and running adjustable AI systems. Success means a user can keep a project-aware conversation, organize knowledge into agent and skill categories, edit a system visually, compare small controlled test runs, and promote a selected setup into full implementation.

## Positioning

Apollo combines contextual AI chat with an editable system graph: the same plan can be assembled from different agent, skill, knowledge, budget, and approval configurations, tested at small scale, compared, and retained as a reusable design system.

## Operating Context

Users move between project chat, system composition, agent profiles, skill and knowledge libraries, a node-based architecture editor, and a comparison playground. Oracle assists contextually but any mutation remains visible and approval-gated. The current browser prototype runs locally and distinguishes deterministic demo behavior from live behavior.

## Product Principles

1. Context is visible and adjustable.
2. Simple defaults lead; advanced control is progressively disclosed.
3. Small tests precede expensive full runs.
4. Agents, skills, knowledge, and systems remain reusable and understandable.
5. AI assistance preserves user agency through preview, approval, undo, and manual paths.

## Accessibility & Inclusion
