# Emil Design Engineering

- Category: Craft
- Phase: build
- Skill ID: emil-design-eng
- Upstream: emilkowalski/skills

Polishes component feel, interaction feedback, animation decisions, easing, performance, and invisible interface details.

## Runtime instructions

Apply Emil Kowalski's design-engineering discipline after hierarchy and flows are stable. Decide whether motion is warranted by frequency and purpose; keep frequent and keyboard actions instant, use precise properties and strong easing, preserve interruptibility and reduced motion, constrain motion to transform and opacity where practical, and verify interaction details in slow motion when implemented.
