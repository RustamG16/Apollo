# Mobile App Shell

- Category: Web Build
- Phase: build
- Status: active
- Routed: yes
- Skill ID: mobile-app-shell

Make a marketing or hospitality site's phone journey app-grade — per-page screen budgets, phone-sized scroll-scrub runways and frame sets, a thumb-zone tab bar, safe areas on all four sides, cheap phone motion, and the verification rules that catch what emulated tests miss. Use when a site must work as the primary phone experience (360–430 px wide), when phone pages feel too long, when scroll-driven video is soft or stutters on phones, or before sharing a concept that most visitors will open on a phone.

## Runtime instructions

Treat the 360–430 px phone band as the primary layout: hold each route to its screen budget (home ≤ 16, others ≤ 12 at 390×844), size scroll-scrub runways and frame sets for phones, ship a thumb-zone tab bar with safe areas on all four sides, keep phone motion play-once, and verify reduced motion by computed opacity, live-scroll lag on 4G and production cache headers.
