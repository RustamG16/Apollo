# Modern Web Guidance

- Category: Web Build

Looks up current web-platform patterns (dialog, popover, anchor positioning, container queries, View Transitions, scroll-driven animation) before they are hand-built.

## Runtime instructions

Before implementing a UI pattern the platform may now provide natively, run one focused search and retrieve only the guide that matches; apply its fallbacks. Skip for patterns already settled in DESIGN.md or the build plan. Offline, grep the bundled guides/ and read one file.
