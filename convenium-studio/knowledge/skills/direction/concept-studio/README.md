# Concept Studio

- Category: Direction
- Phase: direct
- Status: active
- Routed: yes
- Skill ID: concept-studio

Produces the one direction the approved brief specifies, in full: layout, type, media, motion, mobile, asset needs and risk. Alternatives only on explicit request.

## Runtime instructions

Detail the one direction the brief specifies — structure, hierarchy, media, motion, mobile behavior, assets, and risk, not only color. Produce alternatives only when the user asks, stating how many and why.
