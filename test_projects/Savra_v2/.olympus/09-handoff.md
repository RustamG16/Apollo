# SAVRA handoff

## Delivered

- Vite + React + TypeScript single-page implementation
- Self-hosted editorial serif, narrow grotesk, and tabular mono typography
- Threshold hero, cinematic crossing, editorial room, chef sequence, seasonal dish atlas, reservation interlude, and closing room
- GSAP/ScrollTrigger motion with React-scoped cleanup
- Native mobile snap rail and persistent mobile reservation action
- Accessible prototype reservation dialog and explicit unsupplied-fact labels
- Central media manifest and responsive/lazy loading policy

## Commands

- `npm run dev` — local development
- `npm run build` — production build and typecheck
- `npm run preview` — inspect the production output
