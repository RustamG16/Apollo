# ConardLi/garden-skills

Five skills, none installed. High star count (11.5k) but the oldest push date in the set
(2026-07-12, ~7 weeks stale at verification). Not abandoned, but not actively moving.

## The five

| Skill | Relevance |
|---|---|
| `web-design-engineer` | **The relevant one.** Design-to-implementation for web. |
| `kb-retriever` | Knowledge-base retrieval. Overlaps what MNEMOSYNE + `library/` already do. |
| `beautiful-article` | Long-form article formatting. Peripheral. |
| `gpt-image-2` | Image generation via GPT-Image-2. Peripheral — the Adobe and media MCPs cover this. |
| `web-video-presentation` | Video presentation generation. Peripheral. |

## Assessment

The star count overstates the value *for this system*. Four of five skills sit outside
design work, and `kb-retriever` duplicates infrastructure that already exists here in a
form better suited to the task.

`web-design-engineer` is worth reading against the installed `frontend-design`,
`impeccable` and `web-design-pro` before deciding it adds anything — the three installed
skills already cover design-to-code, and a fourth overlapping skill makes the routing
decision harder, not easier.

The repo also ships `dist/`, `website/` and `demo/` directories, so it is packaged as a
product rather than a plain skill collection. Take the skills, not the packaging.
