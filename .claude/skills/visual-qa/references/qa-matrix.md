# Minimum QA matrix

| Area | Checks |
|---|---|
| Visual | hierarchy, grid, type, crop, contrast, consistency |
| Responsive | reorder, overflow, tap size, safe areas, orientation |
| Interaction | states, feedback, interruptibility, keyboard, touch |
| Motion | timing, repeated use, reduced motion, no scroll trapping |
| WebGL | loading, fallback, resize, pause, cleanup, weak-device tier |
| Content | wrapping, missing/long content, links, CTA clarity |
| Runtime | console, network, errors, layout shift, hydration/navigation |
| Accessibility | semantics, focus, labels, contrast, motion preference |
